# 테스트 계획

## 대상과 목적
PM 착수일 역산 계산기(`app/index.html`)가 출시일에서 단계별 착수일을 바르게 거꾸로 계산하는지, 입력 오류와 저장, 데이터 보정이 안전하게 동작하는지 브라우저에서 확인합니다.

## 범위

| 우선순위 | 영역 | 이유 |
|---|---|---|
| 1 | 착수일 계산, 공휴일과 주말 제외 | 계산이 틀리면 도구를 쓸 이유가 없음 |
| 1 | 잘못된 입력 차단 (인원 0, 형식이 다른 JSON, 필수 열 없는 CSV) | 잘못된 값이 들어가면 화면이 멈추거나 결과가 틀어짐 |
| 2 | 저장과 불러오기 | 사용자가 입력한 설정을 잃으면 다시 입력해야 함 |
| 2 | 콘텐츠와 단계 편집 | 가장 자주 쓰는 조작 |
| 3 | 데이터 보정, 좁은 화면 | 자주 쓰지는 않지만 깨지면 눈에 띔 |

## 제외 범위
- 계산 엔진의 모든 조합: 엔진 단위 테스트(무작위 400회 검사)로 따로 확인했고, E2E는 화면에서 보이는 대표 경로만 봅니다.
- 클립보드 복사: 브라우저 권한에 따라 결과가 달라서 제외했습니다.
- 성능: 화면 하나짜리 정적 페이지라 대상에서 뺐습니다.

## 환경
- 기준일 고정: 2026-11-24 10:00, Asia/Seoul, ko-KR
- 브라우저: Chromium, Firefox, WebKit, 모바일 Chrome(Pixel 7)
- 테스트마다 새 브라우저 컨텍스트를 써서 저장된 상태가 섞이지 않게 함

## 통과 기준
- 모든 시나리오 통과
- 테스트 중 페이지 자바스크립트 오류 0건
- 같은 테스트를 3회 반복해도 결과가 같을 것

## 기대값의 근거
기본 설정, 기준일 2026-11-24에서 배포일 2027-02-25의 착수 마감일은 2027-01-21이고 남은 근무일은 40일입니다. 2027-02-08과 02-09는 설 연휴라 기획 검수가 02-05에 끝나면 개발은 02-10에 시작해야 합니다.
